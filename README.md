# AI Notes

A personal study and revision repository for Artificial Intelligence, Machine Learning, Deep Learning, and Large Language Models (LLMs).

## Study materials

- **[01 — Foundation Course](./01-foundation-course.md)** — foundational concepts and a starting point for structured learning.
- **[02 — AI, ML, Deep Learning & LLMs](./02-ai-ml-deep-learning-llm.md)** — detailed notes for studying and revising core AI/ML concepts and LLM-related topics.

## How to use this repository

1. Start with the foundation course and work through the concepts in order.
2. Use the detailed AI/ML/LLM notes to deepen your understanding.
3. Revisit the notes regularly and add examples, diagrams, and practical lessons as you learn.
4. Connect the theory to hands-on projects and experiments.

This repository is maintained as personal study material. Its purpose is to build a clear, reusable knowledge base for learning AI concepts and revising them when needed.
